# Evolabs Agent Studio

**Evolabs Agent Studio 0.8.0-beta.2** 是本機優先的 AI 短劇製作工作室。它把劇本理解、製作討論、角色與場景規格、分鏡、真正的影片模型工作、逐鏡審核、聲音與剪輯放在同一個桌面應用程式中。

本 Beta 的核心原則是：**沒有真實模型回覆，就不顯示 AI 對話；沒有真正影片模型輸出，就不標示為 AI 影片。**

## 產品流程

```text
劇本
  → AI 編劇確認任務並分析故事
  → 製作團隊建立角色、場景、分鏡與聲音規格
  → 導演檢查可生成性與連戲
  → 逐鏡呼叫真正的影片模型
  → 每個鏡頭完成品質檢查與人工核准
  → 配音、字幕、音效與剪輯
  → 輸出成片
```

使用者可以直接與編劇、導演、角色設計師、場景設計師、分鏡師、聲音導演等 Agent 交流。Agent 的回答可以形成可預覽的專案修改提案；只有使用者確認後才會套用。

## 真實 AI 對話與執行證據

對話區只顯示：

- 使用者實際送出的訊息；
- 本機模型實際回傳的最終回答。

模型請求、等待、驗證、錯誤、重試與 Token 統計放在獨立的「系統活動」區，不會冒充 Agent 對話，也不會顯示或偽造模型的隱藏思考過程。

每次 Agent 執行都保存：

- 模型與服務識別；
- request ID；
- 開始與完成時間；
- 延遲與 Token 使用量；
- 任務確認、收到的輸入、限制與缺少資料；
- JSON／Schema 驗證結果；
- 產生或修改的交付物。

若本機 AI 執行環境未連線、模型不存在、回覆無法驗證或資料不足，該工作會明確停止，不會使用預寫文案或規則式結果假裝完成。

## 影片生成模式

### AI 影片

AI 影片模式使用本機 **ComfyUI API 工作流**逐鏡生成真正具有時間序列的影片。工作流必須：

- 可從本機 `127.0.0.1` 或 `localhost` 連線；
- 使用 ComfyUI API 格式 JSON；
- 包含 Evolabs 所需的提示詞、負向提示、Seed、幀數、幀率與逐鏡輸出名稱綁定；
- 具有可辨識的影片輸出節點；
- 最終輸出 MP4、WebM 或其他受支援的影片檔，而不是單張圖片。

Evolabs 會拒絕只輸出 PNG／JPG 的工作流。逐鏡輸出名稱綁定可隔離不同鏡頭與重試產物，避免讀到上一個鏡頭的舊檔。參考圖轉影片工作流會要求每個鏡頭只有一名角色，且該角色已由使用者匯入身份參考圖；多人鏡頭必須拆分或改用支援多人參考的工作流。每個鏡頭還會執行解碼、時長、黑畫面與凍結畫面檢查，並要求使用者核准後才可進入成片。

### 動態漫畫

動態漫畫使用靜態畫面、字幕、聲音與簡單運鏡。這是獨立模式，介面與成片資訊都會明確標示「不是影片模型生成」，不會再冒充 AI 影片。

## 人物與內容品質

角色與鏡頭規格會固定年齡、身份、服裝與外觀，並加入正常人體、完整服裝、禁止裸露、禁止額外眼睛／頭部／肢體、禁止年齡與服裝漂移等生成約束。

製作工作區提供角色身份參考圖管理。參考圖必須由使用者明確匯入；更換或移除後，所有相關鏡頭、人工核准與舊成片狀態都會失效，必須重新生成及審核。

0.8.0-beta.2 目前採用：

- 生成前的嚴格角色與鏡頭規格；
- 影片檔確定性檢查；
- 每鏡人工檢查清單；
- 退回、附註與限次重新生成。

本 Beta **不宣稱**已內建可靠的自動人體畸形或裸露視覺分類模型。未通過人工核准的鏡頭不能進入最終影片。

## 模型與本機執行環境

Evolabs 將兩種模型服務分開管理：

1. **Agent 模型**：負責理解劇本、交流、規劃與結構化交付；使用本機 OpenAI 相容端點。
2. **影片模型服務**：負責逐鏡影片生成；目前使用可匯入的本機 ComfyUI API 工作流。

舊版 Stable Diffusion 1.5 模型包只保留為「動態漫畫／參考圖模型（選配）」，不再稱為影片核心。

### RTX 3050 Laptop 4 GB

4 GB VRAM 對真正影片模型僅屬實驗性相容。實際可用性取決於工作流、模型量化、解析度、幀數、CPU offload 與系統記憶體。Evolabs 不會在影片模型無法執行時，偷偷改用圖片運鏡並宣告成功。

## 安裝與更新

一般使用者安裝 GitHub Release 提供的 Windows `Setup.exe`。已正確安裝簽章更新版本後，可在 Evolabs 內檢查更新並重新啟動。

發佈者第一次設定使用：

```text
SETUP_AUTO_UPDATE.bat
```

本機建置與發布分成兩個步驟：

```text
1_BUILD_AND_TEST.bat
2_PUBLISH_RELEASE.bat
```

第一個腳本完成測試、Engine、NSIS 與 updater 簽章；第二個腳本只上傳已建置的發行檔案，不會重新編譯。

更新私鑰存放在：

```text
%USERPROFILE%\.evolabs\updater
```

私鑰不得上傳、分享或放入專案來源碼。

## 開發與驗證

```bash
npm ci
npm run check
npm test
npm run build:web
python scripts/validate-source-release.py
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

Engine 測試：

```bash
PYTHONPATH=engine/src python -m pytest engine/tests -q
```

`1_BUILD_AND_TEST.bat` 在本機執行 Engine 打包、圖示生成、Tauri NSIS 建置與更新簽章；`2_PUBLISH_RELEASE.bat` 產生 `latest.json` 並上傳發行檔案。

## Beta 邊界

0.8.0-beta.2 是架構、交互、受管理影片引擎與儲存管理重製版。升為穩定版前，必須完成至少一套真實影片工作流的 Windows 實機端到端驗證，包括：

- Agent 真實回答與修改提案；
- 多鏡頭影片生成；
- 逐鏡退回／重新生成；
- 人物、服裝、年齡與連戲人工驗收；
- 最終成片輸出；
- RTX 3050 4 GB 的實際相容性紀錄。
