Evolabs Agent Studio v0.8.0-beta.2 — 開始使用
================================================

這是公開測試版本。AI 對話只顯示真實模型回覆；AI 影片模式只接受真正影片模型輸出。
舊版靜態圖片加運鏡流程已獨立為「動態漫畫」，不會再標示為 AI 影片。

一般使用者
----------
1. 安裝 GitHub Prerelease 提供的 Windows Setup.exe。
2. 開啟「模型」頁面，完成 Agent 模型連線測試。
3. 使用 AI 影片模式時，匯入可用的本機 ComfyUI API 影片工作流並通過驗證。
4. 回到「開始製作」，貼上劇本並先交給 AI 編劇。
5. 檢查模型的真實回覆與任務確認，再建立完整製作計畫。
6. 每個影片鏡頭完成後，逐項檢查人物、服裝、年齡、動作與連戲；只有核准鏡頭才能進入成片。

重要限制
--------
- Runtime 或模型未連線時，Evolabs 會停止工作，不會偽造 Agent 回覆。
- 只輸出圖片的 ComfyUI 工作流不能用於 AI 影片模式。
- RTX 3050 Laptop 4 GB 對真正影片模型僅屬實驗性相容。
- 本 Beta 尚未宣稱能自動辨識所有人體畸形或裸露問題，因此逐鏡人工核准不可略過。

發佈者第一次設定
----------------
1. 完整解壓縮來源包。
2. 雙擊 SETUP_AUTO_UPDATE.bat。
3. 依畫面完成 GitHub 登入、更新簽章金鑰與公開更新通道設定。
4. 安全備份：%USERPROFILE%\.evolabs\updater

本機建置與發布
----------------
1. 雙擊 1_BUILD_AND_TEST.bat。
2. 等待完整 Windows 品質檢查、Engine 建置、NSIS 安裝程式與 updater 簽章完成。
3. 安裝並實際測試 release\v目前版本 內的 Setup.exe。
4. 確認可用後，雙擊 2_PUBLISH_RELEASE.bat，上傳已建置的 EXE、.sig、SHA-256 與 latest.json。

第一次發布前仍須執行 SETUP_AUTO_UPDATE.bat，以建立並備份本機更新簽章金鑰。
建置與發布已分開；發布階段不會重新編譯，也不會重跑已完成的本機建置。
